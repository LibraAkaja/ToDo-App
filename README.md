# 📝 ToDo App (React)

A simple and interactive **ToDo application built with React** that allows users to add, edit, delete, and manage tasks with persistent storage using the browser’s `localStorage`.

---

## 🚀 Features

- ➕ Add new tasks
- ✏️ Edit tasks inline  
  - Click the edit icon to enable editing  
  - Press **Enter** or click outside to finish editing
- 🗑️ Delete individual tasks
- ❌ Delete all tasks at once
- 👀 Show more / show less / show all tasks
- 💾 Persistent storage using `localStorage`
- 🎨 Visual edit indicator using grayscale toggle on edit icon

---

## 🛠️ Built With

- React (Functional Components & Hooks)
- JavaScript (ES6+)
- HTML
- CSS
- Browser localStorage API

## ⚙️ How It Works

- State is managed using React useState
- Side effects handled using useEffect
- Tasks are stored and synced with localstorage
- UI is fully state driven
